# Traffic Management System (Simulation)  
The purpose of the Traffic Management System (Simulation) is to simulate basic traffic flow using queues and traffic signals. The system allows vehicles to enter traffic lanes, wait in queues, and move according to traffic signal states and predefined traffic rules.

The system will simulate vehicle movement through traffic lanes using queues. It will manage traffic signals, vehicle queues, congestion, and basic traffic statistics such as waiting time, queue length, and vehicles processed. The system will be implemented using C/C++ and will function as a simulation rather than controlling real-world traffic.
